Python (Pyodide) 🧪
This enables Python support through Pyodide. Use the OEEL function to load a Python file. The environment is preimported with ee, oeel, and Map. Each new run will have its own context; therefore, changes made in a previous run will normally have no effect. Some standard packages, such as numpy and matplotlib are preinstalled.
